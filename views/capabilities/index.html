    对话与调用

    选择理解日常需求、决定调用哪些工具的模型。分析模型在“分析适配”页面设置。

    留空沿用 AstrBot 当前模型。手动选择后，作用于允许会话中的本地 Agent 对话和工具调用，不额外增加一轮模型请求；第三方托管 Agent 不切换。

    操作确认

    开启时按每项能力的调用方式确认。关闭后省去确认步骤，“仅管理员”和原插件权限仍然有效。

    切换开关会取消旧的待确认操作，不会自动执行。原生工具继续沿用 AstrBot 与原插件自己的控制。

    使用范围

    以下范围仅控制本插件的自然语言入口，不影响机器人原有指令或其他插件。黑名单优先，管理员也遵守。

    开启后只有白名单中的群可以使用；开启但名单为空时，所有群均不允许。

    可填写普通 ID，或 平台名:ID，例如 aiocqhttp:123456。每行一项，也可以用逗号分隔。
