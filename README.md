# 能力桥 · Capability Bridge

AstrBot 插件的自然语言能力入口，当前为公开测试版。

给 AstrBot 的插件能力增加自然语言入口。用户说“帮我查一下群里小明的今日总结”，模型可以查找能力、解析参数，再调用原插件完成。

插件本身不附带任何游戏或业务插件的适配。适配规则由你选择的模型根据当前已安装插件的注册信息和源码生成，校验后保存到独立数据目录。

## 安装

在 AstrBot 后台的插件页选择“安装插件 → 从链接安装”，填写：

```text
https://github.com/YuuKi-Z/astrbot_plugin_capability_bridge
```

安装后打开插件的“能力中心”视图。通过仓库安装即可使用，不需要插件市场收录。

## 使用

需要 AstrBot **4.29.0 或以上、5.0 以下**，以及支持工具调用的聊天模型。

1. 安装插件后，在 AstrBot 后台的插件页打开“能力桥”。
2. 进入可视化视图“能力中心”（目录名 `capabilities`）。
3. 选择已经在 AstrBot 配置好的分析模型，点击“保存设置”。不需要再填一份 API Key。
4. 点击“刷新扫描”查看目录。这一步不调用模型。
5. 点击“一键适配变更”，或在某个插件旁点击“分析适配”。运行过程中可查看 token 用量，也可停止剩余分析。框架自动分批，不需要设置 token 预算。
6. 开始对机器人描述需求。聊天模型通过 `capability_find` 查找功能，再通过 `capability_run` 执行适配能力。已经可用的原生工具直接调用。

新装、更新插件后，再点击扫描和适配。Python 源码或版本发生变化时，旧适配停止执行。重新适配同一版本失败时保留已有规则。可单独停用某项能力。

能力桥不会改变机器人何时被唤醒；群聊读空气、@唤醒、白名单等依然由现有配置决定。自然语言请求需要先进入聊天模型流程。若人格明确限制工具范围，需确保两个桥接工具在允许范围内。

## 能处理的接口

| 接口 | 处理方式 |
| --- | --- |
| 已注册的普通命令、命令组子命令 | 分析参数与源码，生成调用映射 |
| 插件已经注册的 LLM 工具 | 检索当前请求实际可用的工具，由模型直接调用 |
| 直接从事件正文读取关键词的命令 | 根据源码证据，将文本参数放回原指令后的消息正文，再调用原方法 |
| 单个群成员绑定账号的查询 | 识别有源码证据的只读 getter 和常量提示，将目标账号传给原指令的显式账号参数 |
| 定时器、任意消息监听等自动行为 | 保持其原有自动运行方式；没有明确调用接口时不自动包装 |
| 需要多轮交互、双人绑定、复杂参数重载等 | 无法校验时标记为未适配，显示原因 |

“自动适配”表示自动生成并检查声明式规则，不代表能可靠理解所有任意业务逻辑。复杂插件可能只有部分功能通过校验。

## 执行与权限

- 只接受已有命令 ID、已有参数，以及源码检查通过的绑定查询方法。模型不能生成或执行 Python、shell、SQL。
- 调用前检查插件、命令、所属命令组、当前会话和原生权限过滤器；保留实际发送者身份。群友账号作为查询参数传入。
- 群成员按当前群的 QQ 号、@提及、群名片或昵称解析；重名时要求明确对象。不会用请求者账号代替无法识别的目标。
- 未绑定时返回从原插件源码提取的常量提示；查询和结果发送由原 handler 完成，包括原插件的图片输出。
- 自定义过滤器会检查重建的命令事件。依赖框架其他阶段特殊副作用的插件可能仍不兼容，不能将静态检查等同于完整业务验证。
- 单次消息中同一能力、同一参数重复调用会复用结果，减少重复操作。执行失败或超时不会自动重试业务操作。
- 管理 API 使用 AstrBot 后台登录鉴权。扫描不读取插件私有配置或绑定表；执行绑定查询时只使用已解析的目标 ID。

## 模型与数据流

点击分析适配后，相关插件的注册信息、处理方法源码片段和辅助方法源码片段会发送给所选分析模型服务。日常对话复用已生成的规则，用户明确重新适配或插件发生变化时才重新分析。

分析模型复用 AstrBot 已配置的服务提供商；本插件的状态文件不保存 API Key。生成规则保存在运行实例的数据目录中，不包含在本仓库。测试中的成员、账号与会话均为人工构造的示例。

## 用量

界面只需要选择分析模型；源码输入与模型输出的分批限制由框架内部管理。已经适配且没有变化的插件，一键适配时会跳过。需要分析的插件不会因为旧的整轮 token 预算而中途停止。

模型返回后按服务商报告的实际用量统计。服务商不报告用量、请求取消或超时时，界面保留估计量。停止按钮可以取消剩余任务，但不能保证撤回已经发送给服务商的请求。

日常聊天不重复分析源码；仍会产生正常聊天、能力检索与工具调用所需的模型 token。适配成本主要取决于插件源码、命令数量、模型输出和推理用量。

## 数据与卸载

规则和设置保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_capability_bridge/state.json`。分析模型沿用 AstrBot 已配置的凭据，状态文件不存 API Key。

卸载插件即可停止桥接，不修改业务插件源码。默认安装包不包含任何服务器生成的适配或账号数据。迁移生成规则时需同时核对目标插件版本和源码指纹。

## 兼容范围

当前主要验证环境为 AstrBot 4.29.0、QQ OneBot v11。群成员绑定解析依赖平台成员查询能力；其他平台需要进一步验证。

本插件使用 AstrBot 的内部命令注册与过滤器接口，后续 AstrBot 版本可能需要兼容更新。复杂插件依赖的额外事件流程也可能影响调用结果。

## 验证

在 AstrBot Python 环境中，从插件父目录执行：

```sh
python -m unittest astrbot_plugin_capability_bridge.tests.test_bridge -v
```

测试使用模拟群成员、模拟账号与发送通道，不向真实 QQ 会话发消息。
